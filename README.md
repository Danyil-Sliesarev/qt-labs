# Practical Assignments

This repository contains practical work for the course
**Розробка застосунків зі штучним інтелектом**. Each practical assignment is
kept in a separate directory and may use a different technology.

## Assignments

- [`pr2/`](pr2/) — Practical Work №2: local object detection with YOLO,
  FastAPI, and a browser interface.

The `scoreboard/` and `converter/` directories are empty placeholders from the
initial repository setup; they are not completed assignments.
