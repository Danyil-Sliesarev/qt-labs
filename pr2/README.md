# Практична робота №2: Локальний inference спеціалізованої моделі

## Мета

Створити вебзастосунок для локального виявлення об'єктів на зображенні за
допомогою попередньо навченої YOLO. Застосунок показує назви класів, рамки,
оцінки впевненості, кількість об'єктів і час inference. Зображення та
обчислення залишаються на комп'ютері користувача; зовнішні AI API не
використовуються.

## Технології

- Python, FastAPI та Uvicorn
- Ultralytics YOLOv8n (`yolov8n.pt`) і PyTorch
- Pillow для перевірки та декодування зображень
- HTML, CSS і JavaScript для інтерфейсу
- pytest та HTTPX для автоматизованих тестів

Файл ваг `yolov8n.pt` і віртуальне середовище не додаються до Git. Ваги
завантажуються Ultralytics автоматично під час першого запуску, якщо їх ще
немає в `pr2/`. Учительський архів або початковий каркас `pr2` у наданому
робочому просторі відсутній, тому застосунок створено з нуля за вимогами
завдання.

## Встановлення та запуск (Windows PowerShell)

Потрібен Python 3.10 або новіший. У цій роботі встановлення та перевірку
виконано на Python 3.14.3 з PyTorch CPU.

```powershell
cd pr2
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python check_env.py --image eval/images/cat.jpg
python -m uvicorn app.main:app --reload
```

Під час першого запуску Ultralytics завантажує офіційні ваги `yolov8n.pt`.
Потрібне інтернет-з'єднання лише для цього першого завантаження та
встановлення залежностей; inference після цього виконується локально.

Відкрийте <http://127.0.0.1:8000/>. Перевірити готовність моделі можна за
адресою <http://127.0.0.1:8000/health>.

## Використання інтерфейсу

1. Виберіть зображення або перетягніть його у зону завантаження.
2. За потреби змініть поріг впевненості повзунком (за замовчуванням `0.25`).
3. Натисніть **Detect objects**.
4. Перегляньте рамки на зображенні, список класів і координат, кількість
   знайдених об'єктів та час inference.

Підтримуються JPEG, PNG, WebP, GIF і BMP. Максимальний розмір файла — 10 MiB,
максимальний розмір зображення — 25 мегапікселів.

## Як працює inference

`app.main` завантажує ваги один раз під час запуску застосунку через lifespan
FastAPI. Посилання на модель зберігається в `app.state` і повторно
використовується запитами. `app.inference.load_model()` вибирає CUDA, якщо
вона доступна, інакше CPU; `detect()` запускає модель у режимі
`torch.inference_mode()`.

YOLO повертає класи, координати рамок і впевненість. Результати перетворюються
на звичайні Python-числа та рядки, придатні для JSON. Детекції нижче
заданого порога відкидаються. Час вимірюється через `time.perf_counter()` і
повертається в мілісекундах; це час виклику моделі для одного зображення,
без урахування завантаження файла та стартового завантаження ваг.

Якщо CUDA недоступна, використовується CPU. Завантаження ваг або помилки
inference записуються в журнал сервера; клієнт отримує безпечне повідомлення
без stack trace. `/health` повертає `503`, доки модель не готова.

## API

- `GET /` — вебінтерфейс.
- `POST /detect` — multipart-поля `file` та необов'язковий `confidence`
  (`0.0`–`1.0`, типове значення `0.25`).
- `GET /health` — статус застосунку та готовності моделі.

Невалідний/порожній вміст зображення повертає `400`, завеликий файл або
зображення — `413`, непідтримуваний тип — `415`, некоректний поріг — `422`.
Помилка inference повертає `500`, помилка завантаження моделі — `503`.

Приклад формату відповіді `POST /detect` (значення наведено лише для
демонстрації формату):

```json
{
  "detections": [
    {
      "class_id": 0,
      "class_name": "person",
      "confidence": 0.92,
      "bbox": {"x1": 100, "y1": 50, "x2": 350, "y2": 470}
    }
  ],
  "count": 1,
  "inference_time_ms": 85.4,
  "confidence_threshold": 0.25
}
```

## Оцінювання

П'ять реальних зображень з відкритими ліцензіями перевірені на трьох порогах.
Розмітка вручну зіставляється з передбаченнями за IoU не менше `0.5`.
Фактичні підсумки, виявлені помилки, джерела фотографій і ліцензії наведені
в [`eval/evaluation.md`](eval/evaluation.md). Перезапустити оцінювання:

```powershell
python -m eval.evaluate
```

## Тести

```powershell
python -m pytest -q
```

Тести ізольовано перевіряють API та інференсну логіку з підставною моделлю.
Окреме реальне CPU-оцінювання п'яти фотографій виконується командою
`python -m eval.evaluate`.

## Обмеження

- YOLOv8n використовує фіксований набір класів COCO і може помилятися на
  незвичних ракурсах, частково закритих або малих об'єктах.
- Вищий поріг може зменшити хибні спрацювання, але збільшує кількість
  пропущених об'єктів.
- Час inference залежить від CPU/GPU, розміру зображення, першого прогріву
  моделі та навантаження системи.
- Набір із п'яти фотографій призначений для навчальної демонстрації, а не для
  статистично репрезентативної оцінки моделі.
